# STELLA — лендинг (Next.js + Tailwind)

Одностраничник по архитектуре из ТЗ: hero → повтор оффера → Гарантия
гладкости → результаты до/после → услуги и цены (табы) → косметологи →
отзывы → FAQ → форма записи → футер с двумя студиями. Все пункты меню
в шапке — якоря на секции этой же страницы, не отдельные роуты.

## Запуск локально / в Replit

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

Чтобы импортировать в Replit: создать Repl по шаблону Next.js
(или пустой Node.js) и загрузить содержимое этой папки, либо
залить в GitHub-репозиторий и сделать Import from GitHub в Replit.

## Куда класть свои фото

Все изображения — в `/public/images/...`, ссылка в коде — просто
`/images/имя-файла.webp` (без `import`).

Места, где сейчас стоят цветные заглушки — с пометкой `TODO` в коде:

- `components/Hero.tsx` — `hero-model.webp` (портрет, ~900×1125)
- `components/PromoStrip.tsx` — `promo-hands.webp`
- `components/Results.tsx` — пары `results/{зона}-before.webp` / `-after.webp`
- `components/Masters.tsx` — фото мастеров (квадратные)
- `components/Reviews.tsx` — аватары клиенток

Рекомендации: WebP, сжатые (Squoosh/TinyPNG), латиница без пробелов
в названиях файлов — это прямо влияет на LCP на мобильном трафике.

## Куда падают заявки с формы записи

Сейчас форма (`components/BookingForm.tsx`) отправляет данные на
`app/api/booking/route.ts`, который пересылает заявку в Telegram-чат
администраторов через Telegram Bot API. Это временное MVP-решение,
пока нет прямой интеграции с Altegio/amoCRM.

Настройка в Replit (вкладка **Secrets**, не в коде — иначе токен
попадёт в публичный репозиторий):

1. Создать бота через `@BotFather` в Telegram → получить токен →
   положить в Secret `TELEGRAM_BOT_TOKEN`.
2. Добавить бота в чат/группу, куда должны падать заявки.
3. Узнать `chat_id` этой группы (например через `@getidsbot`, либо
   написав что-то в группу и открыв
   `https://api.telegram.org/bot<TOKEN>/getUpdates`) → положить в
   Secret `TELEGRAM_CHAT_ID`.

После этого заявки с сайта будут падать прямым сообщением в чат —
администратор увидит имя, телефон и зону сразу.
